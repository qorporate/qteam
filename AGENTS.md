# QTeam agent instructions

- Read `DESIGN.md` before changing any user interface. It is QTeam's design source of truth.
- Build UI with Tailwind utility classes in Svelte markup. Keep `src/routes/layout.css` limited to
  the Tailwind import, design tokens, and essential global styles.
- Do not add product patterns, component CSS, or abstractions for future versions.
- Read the relevant section of `docs/qteam_flow.md` before changing product behaviour, and stay
  within the requested delivery version.
